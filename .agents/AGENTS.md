# PROJECT RULES & CONVENTIONS

## Toast Messaging Rules (Applies to all platforms: iOS, Android, Desktop, Web)
1. **Toast Lifetime**: Any and all toast messages must appear strictly for a maximum duration of **5 seconds**.
2. **Immediate Dismissal**: Toast messages must disappear immediately on **any user navigation input** or when the 5 seconds expire, whichever comes first.
3. **No Persistent Toasts**: No toast message shall stay persistent on any screen anywhere in the system beyond 5 seconds or across any user navigation input/screen switch.
